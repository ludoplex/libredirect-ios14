LibRedirect for iOS 14

Turns YouTube, Reddit, X, TikTok and other links into privacy front-end links. Runs in Safari 14 on an iPhone 7. No extension, no account.

Bookmarklet (redirect the page you are on)

  1. Bookmark this page (Share, Add Bookmark).
  2. Edit that bookmark and replace its address with the code below.
  3. On a YouTube or Reddit page, open Bookmarks and tap it.

LibRedirect

Shortcut (convert a link before you open it)

  1. Shortcuts app, new shortcut. Turn on "Show in Share Sheet", accept URLs.
  2. Add "URL Encode" with the Shortcut Input.
  3. Add "Text": the address below, then the URL Encode result.
  4. Add "Open URLs" with that Text.

Services

Settings stay in this browser (localStorage). Source: ludoplex/libredirect-ios14, a fork of LibRedirect (GPL-3.0).
